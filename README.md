# Что делает скрипт
Находит следующие ошибки в предпечатной подготовке .ai файла:
- дробные значения CMYK
- суммы CMYK выше 280
- фотографии не в формате TIFF
- не встроенные изображения
- не переведенная в кривые обводка
- не переведенный в кривые текст

Любую из проверок можно отключить. Некоторые можно дополнить — например не проверять слой CUT на наличие незакривленной обводки.

# Установка
Скачайте файл prepress_laboratory.jsx и переместите его в эту папку:

`C:\Program Files\Adobe\Adobe Illustrator 2025\Presets\en_US\Scripts`

Либо в эту, если у вас русскоязычная версия:

`C:\Program Files\Adobe\Adobe Illustrator 2025\Presets\ru_RU\Scripts`

# Использование
1. В Illustrator: `File > Scripts > Other Scripts` (или Ctrl+F12)
2. Находите путь куда ранее поместили файл
3. Клик-клик

Скрипт запуститься сразу. После первого использования (и перезагрузки Illustrator) он появится в списке скриптов в меню `File > Scripts > prepress_laboratory`
